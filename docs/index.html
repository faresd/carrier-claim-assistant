Carrier Claim Assistant Privacy Policy

Effective 1 September 2026

Carrier Claim Assistant helps Amazon Seller Central operators check official carrier status and prepare claims for Colissimo, La Poste, and Chronopost shipments.

Data handled

The extension may read order and shipment details, the recipient name and delivery address, and existing Seller Notes from Amazon Seller Central. A user may save a sender profile and may create editable claim drafts. Confirmed carrier references can be retained with the order.

How data is used

Data is used only to provide the extension's visible delivery-check, claim-preview, carrier-prefill, Seller Notes, duplicate-prevention, return-monitoring, and pickup-alert features. The extension does not send order, recipient, sender, or claim data to the extension developer.

Private cloud sync is off by default. When explicitly enabled, order, recipient, tracking, merchant-account, status, claim, and resolution details are sent to the operator's configured monitor server. That server sends tracking numbers to La Poste's official Suivi v2 API for daily Colissimo, La Poste, and Chronopost checks. Claim form data is submitted directly to the selected carrier's official website only after user confirmation.

Storage and retention

Sender settings, cached audit results, successful claim outcomes, and the optional per-device monitor token are stored in browser extension storage. Pending claim details use browser session storage. Synchronized monitor records remain in the operator's private database until it is removed; Resolved history is retained but excluded from future tracking checks. Pairing codes expire after ten minutes.

Sharing and sale

The extension has no analytics, advertising, or third-party tracking libraries. Data is not sold, rented, or shared for advertising, profiling, or unrelated purposes.

Security and user control

The extension uses Manifest V3 storage, alarms, and notifications plus supported Amazon/carrier pages. Access to a monitor origin is optional and requested for the exact HTTPS server configured by the operator. Carrier API and admin secrets remain server-side, and each paired browser receives a separate revocable token. The extension does not collect account passwords or payment details. Final carrier submission requires explicit confirmation.

Changes and contact

Material changes will be published on this page. The publisher's support email is available on the Chrome Web Store listing.
